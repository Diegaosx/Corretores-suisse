Viabilidade & Arquitetura de Deploy no Railway

Diagnóstico técnico completo sobre como hospedar o TrustCore no Railway com o que já existe no repositório.

Totalmente Viável e Pronto para Deploy no Railway!

O ecossistema do TrustCore (Laravel 11 + MySQL 8 + Painel) pode ser hospedado imediatamente no Railway. Já criamos os arquivos de configuração necessários (backend/Dockerfile, backend/railway.json e docker-compose.yml).

Mapeamento dos Componentes no Railway
Componente Tecnologia Onde Roda no Railway Status de Prontidão
Banco de Dados MySQL 8 (InnoDB) Plugin MySQL Oficial do Railway 100% Pronto (Dump 97 tabelas pronto)
Backend REST API Laravel 11 / PHP 8.2+ Container Dockerfile (PHP-FPM + Nginx) 100% Configurado (Dockerfile criado)
Painel do Corretor Angular 15.2 / Nebular Serviço Nginx Estático no Railway / Vercel Pronto p/ compilação
Robô Power Automate RPA Desktop + Cloud Flow Roda em Máquina/VPS Windows (conecta na API Railway) Híbrido (Desktop externo ➔ API Railway)
App Mobile Anitta Flutter / Dart (iOS/Android) Roda no smartphone dos corretores (conecta na API Railway) Ajustes de API e Function Calling

1 Passo a Passo de Inicialização no Railway

  1. Acesse o Railway.app e crie um novo projeto vazio.
  2. Adicione o serviço MySQL Database (fornece host, usuário, porta e senha).
  3. Importe o dump oficial:
    mysql -h [MYSQL_HOST] -u [MYSQL_USER] -p [MYSQL_DATABASE] < database/TrustcoreDB.sql
  4. Conecte este repositório Git ao Railway e aponte para a pasta raiz /backend. O Railway detectará o Dockerfile automaticamente!
